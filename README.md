## How I build

- **One codebase, many surfaces.** Flutter for mobile *and* web *and* desktop; a single domain layer behind every target, with flavors for different apps (see ShipLink's five deliverables).
- **Security is not a feature toggle.** Row-level security on every user-scoped table, `service_role` keys never on the client, AI keys behind authenticated Edge Functions, payments written only by server-side code with HMAC + amount verification.
- **Deterministic where it matters.** Match scores, CV evaluation and pricing logic are pure functions with tests — LLMs generate text, they don't own numbers.
- **Degrade, don't crash.** Offline caches, stale-while-revalidate premium state, local fallbacks when a migration isn't deployed yet.
- **Bilingual by default.** EN/AR with correct RTL layout and Arabic PDF rendering (shaping, not just fonts).
